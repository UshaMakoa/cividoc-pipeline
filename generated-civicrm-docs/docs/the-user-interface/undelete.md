# Undelete

By default, deleted contacts are sent to the trash. An administrator, or anyone holding the &quot;access deleted contacts&quot; permission, can recover them later.

To restore a contact:

1. Go to **Advanced Search**, enter the contact’s details, and check the **Search in Trash** box at the bottom of the **Basic Criteria** section.
2. From the results, use the **Restore** link at the end of the contact’s row. Alternatively, choose **Restore contacts** from the action drop-down menu.

If you are sure you no longer need a particular contact, you can delete them permanently.

You can disable the trash function in **Administer &gt; System Settings &gt; Misc (Undelete, PDFs, Limits, Logging, etc.)**
