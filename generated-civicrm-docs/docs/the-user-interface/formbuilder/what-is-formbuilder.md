# What is FormBuilder

FormBuilder is a form design workspace for creating custom forms to capture and store information from members, supporters, or staff.

It can also be connected to SearchKit to create a directory, a volunteer portal, or an internal search page tailored to specific criteria.

## Enabling FormBuilder

The extension can be enabled on the extensions page if not already installed. Once enabled, a FormBuilder link will appear in the menu under **Administer &gt; Customize Data and Screens**.

## Editing permissions

There are two permissions for controlling who can create and edit new forms:

* FormBuilder: edit and delete forms
* FormBuilder: edit and delete own forms

## User permissions

You can control who can see a form in the settings for each individual form. If a form is used to display a SearchKit display, you can also control which results are displayed, depending on the user.

This is explained in more detail under SearchKit [permissions](../../searching/searchkit/permissions.md).
