# Types of forms

The main FormBuilder page has several tabs:

## Submission Forms

Use FormBuilder to design custom forms that collect information from members, supporters, or staff. You can build interactive forms for manual data entry, such as creating new contacts or logging specific activities, without needing technical knowledge.

For more details, see [creating data entry forms](creating-data-entry-forms.md).

## Search Forms

You can connect existing SearchKit configurations directly to FormBuilder to create a directory, volunteer portal, or internal search page tailored to specific criteria. Users can then filter CiviCRM records on a dedicated screen.

For more details, see the [searching and reporting](../../searching/searchkit/connecting-searchkit-to-formbuilder.md) pages.

## Field Blocks

Field Blocks are reusable templates for submission forms. By default, CiviCRM has a field block for items that can have more than one, including addresses, emails, and notes, plus a block for each custom field set. You can edit these blocks to suit your site's needs.
