# System Administrator Guide

## Scope of this guide

This guide is for people setting up, maintaining, and upgrading a [CiviCRM](https://civicrm.org) instance for an organization. Installation details are in the separate [Installation Guide](https://docs.civicrm.org/installation/en/latest/).

### System Administrator Guide and User Guide

The [User Guide](https://docs.civicrm.org/user/en/latest) covers functionality available through CiviCRM's web-based interface.

The guides overlap on setup and configuration. In general, the User Guide covers actions users can perform within CiviCRM's interface. The System Administrator Guide covers actions that require work outside the interface, such as file-system or shell access.
