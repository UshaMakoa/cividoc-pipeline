# Switching CMS platforms

Use these guides to move a CiviCRM installation from one CMS to another. If you are changing servers at the same time, also see [Moving an Existing Installation to a New Server or Location](../switch-servers.md).

Guide names follow this format:

    **Current CMS** to **New CMS**

Available guides:

- [Joomla to Drupal](joomla-to-drupal.md)
- [Drupal to Wordpress](drupal-to-wordpress.md)
- [Drupal to Backdrop](drupal-to-backdrop.md)
