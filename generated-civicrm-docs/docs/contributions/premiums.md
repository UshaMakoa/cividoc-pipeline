# Configure premiums

Configure **Premiums**, such as T-shirts or subscriptions, to offer on your contribution pages:

1. Navigate to **Administer &gt; CiviContribute &gt; Premiums (Thank-You Gifts)**.
2. **Edit** an existing **Premium**, or click **Add Premium** to add a new one.
3. Enter the premium’s Name, Description, SKU (an optional product code), Premium Image (an optional image of the item), Minimum Contribution Amount to receive the Premium, Market Value of the Premium, Actual Cost (optional), Financial Type (optional), and Options (e.g. colors and sizes).
4. If you’re offering a Subscription or Service, click **Subscription** or **Service Settings** to define additional information, such as Period Type (e.g., Fixed or Rolling), Fixed Period Start Day, Duration, and Frequency.
