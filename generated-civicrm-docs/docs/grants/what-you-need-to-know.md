# What you need to know about CiviGrant

CiviGrant helps grant-giving organisations manage their grant process. It is one of the simpler CiviCRM components, so if you are familiar with other CiviCRM components, you will probably find it straightforward.

## Key concepts

### CiviGrant workflow

The standard CiviGrant workflow starts with the details of the grant to which a contact is applying, including the amount applied for and when the application was received. You can then record when the grant decision was made, how much was granted, when money was transferred, when the grant report was due, and whether it has been received.

### Grant types

Grant types specify the different types of grant your organisation distributes. You can set up as many grant types as you like and search based on grant type.

### Grant statuses

CiviGrant comes with three default grant statuses: Pending, Granted and Rejected. You can add more grant statuses to match your workflow.

### Application forms and eligibility criteria

You can create application processing forms and eligibility criteria in CiviGrant using CiviCRM's custom data fields. Consider which fields should be attached to the *contact* who has applied for the grant and which should be attached to the *grant*.

## Key questions

Before you begin working with CiviGrant, consider these questions:

- What grant types does your organisation offer?
- What is your grant application workflow, and how can you map it to CiviGrant statuses?
- Do you have an application form, and if so, how can you model it using custom data?
- What kinds of reports do you want to generate from the grant process?
