# Manage grants and recipient reports

These are everyday tasks for administering grants with CiviGrant.

## Use the CiviGrant dashboard

Go to **Other &gt; Grants &gt; Dashboard** to access the CiviGrant Dashboard. It shows a summary of the grants registered in your CiviCRM database and a table of recent grant recipients.

## View grants

There are two ways to view grants:

- The **Grants dashboard** summarizes the status of all grants in your CiviCRM, grouped by grant type, and gives an overview of recent grants.
- To view an individual contact&#39;s grants, open the **Grants** tab on their record.

## Add or edit grant recipients

After Wookie Hole Community Action selected its grant recipients for the Cave Festival, its grant administrator looked up each successful applicant&#39;s contact record and entered a new grant record for each one.

To add a grant recipient:

1. Go to **Other &gt; Grants &gt; New Grant**.
2. Select an already existing contact or create a new contact to whom the grant will be given.
3. Complete the grant details, including any custom data that has been set up. Fill in as many details as possible; you can edit and update them later.
4. Click **Save**.

To edit or update a grant at any time, use the edit link in the grant record.

## Record reports

When a report is received from a grant recipient, edit the grant information from either the CiviGrant dashboard or the contact&#39;s record. Check the **Grant Report Received?** box in the form and add any appropriate notes.
