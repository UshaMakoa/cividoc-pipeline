# CiviCRM User Guide

## Scope of this guide

This guide is for [CiviCRM](https://civicrm.org) users. It covers the functionality available through CiviCRM's web-based interface.

### User Guide and System Administrator Guide

The [System Administrator Guide](https://docs.civicrm.org/sysadmin/en/latest) covers installation, upgrades, and some of the more complicated setup tasks.

The guides overlap on some setup and configuration topics. In general, the User Guide covers actions users can perform within CiviCRM's user interface. The System Administrator Guide covers actions that require work outside that interface, such as file-system or shell access.

### How to search the entire documentation

To use this documentation within the CiviCRM Dashboard, you can use the [docbot-extension](https://civicrm.org/extensions/docbot). See [installing an extension](https://docs.civicrm.org/user/en/latest/introduction/extensions/#installing-extensions) for installation instructions. The extension provides a dashboard widget for quickly searching the CiviCRM documentation.
