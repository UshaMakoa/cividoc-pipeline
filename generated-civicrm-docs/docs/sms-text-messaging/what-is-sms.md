# What is SMS?

SMS stands for Short Message, or Short Messaging Service. It refers to the text messages your mobile phone may send and receive. CiviCRM can send and receive these messages within the system, giving you another way, besides email, to communicate with constituents and track those communications.

Uses include:

- Disseminating information in areas where mobile and landline internet access is unavailable or unstable.
- Collecting information and responses from remote areas.
- Running an SMS marketing campaign.
- Distributing alerts and reminders.
- Notifying event participants—for example, about a last-minute change to a meeting’s location or time.
