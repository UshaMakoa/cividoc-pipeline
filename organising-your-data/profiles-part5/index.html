    Make a searchable directory with a Profile¶

    Use a Profile to let website visitors search selected contact information. You can choose which fields they search, which appear in results and which appear when they view a record.

    Before making the directory public, limit its listings to an appropriate Group. If no Group is selected, a search can expose every record in your database.

    Configure the Profile¶

    1. Create a Profile for the directory.
    2. In its advanced settings, select the Group whose records visitors may view or search.

    For example, a Smart Group of members with a status of New, Current or Grace can provide a dynamic directory of active members.

    Other advanced settings may be useful:

    • Enable mapping: Lets visitors map directory contacts using Google or Yahoo! maps and obtain directions to a record’s address. Mapping must already be enabled at Administer > System Settings > Mapping and Geocoding.
    • Include profile edit links: Adds an edit link to listings for users with permission to edit the contact. This is not commonly needed for a membership directory.
    • Include Drupal user information: On Drupal, adds a link to a contact’s user account information, such as their My Account page, if that contact has a website user account.

    Choose the directory fields¶

    1. Add the fields you want in the directory.
    2. Set every directory field’s Visibility to Public Pages or Public Pages and Listings.
    3. Check Searchable for each field visitors should be able to search.
    4. Check Results Column for each field you want displayed in the results list.

    A field set to Public Pages and Listings is hot-linked in the detail view. Clicking its value starts a search for other records with that value. For example, clicking a City value searches as though the visitor had selected that city on the Profile search screen.

    A field with Results Column checked appears both in the results list and in the record’s detail view. Without that check, it can still appear in the detail view. Setting more fields as Searchable gives visitors more ways to find information.

    The following images show a membership-directory search form, a results list containing fields marked Results Column, and the detail view reached through a view link. The detail view shows all Profile fields.

    Link to the directory¶

    • Drupal: Link to http://www.myorganization.org/civicrm/profile?reset=1&gid=N, where N is the Profile directory’s ID. Add &force=1 to show a result set directly. Add &force=1&search=0 to show the result set and hide the search criteria.
    • Joomla!: In Menu Manager, create a front-end menu item. Select CiviCRM, choose the profile search option, then choose the Profile in the parameters pane.
    • WordPress: Linking to the directory this way is not yet implemented in the source material.

    You can also prepopulate search criteria in the URL. The options are described at Linking Profiles.
